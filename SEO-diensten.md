# SEO — Diensten SK Accounting

Copy-paste per dienst in de CMS (**Diensten → [dienst] → tab "SEO"**).

Per dienst:
- **Titel** → veld `Titel` (collectie Services)
- **Omschrijving** → veld `Omschrijving` (collectie Services)
- **Meta Title** → SEO-tab, veld `Title` (streefwaarde ≤ 60 tekens)
- **Meta Description** → SEO-tab, veld `Description` (streefwaarde 150–160 tekens)
- **Focus-keyword** → niet in CMS; ter info voor de copy/interne links

> **Let op:** de Services-collectie heeft momenteel geen `slug`-veld. Individuele dienstpagina's bestaan (nog) niet — alle diensten worden getoond op `/diensten`. De meta-velden worden dus pas volledig benut zodra er per dienst een eigen URL komt. Wil je dat later, laat het weten (slug-veld + detailpagina + sitemap).
